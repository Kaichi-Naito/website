# Rolling の MIDI 譜面

## 保存先とファイル名

- リポジトリ：`Kaichi-Naito/website`
- フォルダー：`rhythm/charts/`
- ファイル名：**`Rolling_Game.mid`**（小文字）
- 完全なパス：**`rhythm/charts/Rolling_Game.mid`**

このフォルダーに `Rolling_Game.mid` を追加すると、ゲームが起動時に自動で読み込みます。
まだ配置していない場合は、既存のテスト譜面で遊べます。

## 頻繁に作り直して試す場合

1. REAPERでMIDIを編集し、`Rolling_Game.mid` として書き出します。
2. ゲームの「MIDI譜面を読み込む」で、そのファイルを選んでプレイします。
3. 修正後は同じファイルに書き出し、もう一度選びます。同じ名前で何度でも読み込めます。

手元のファイル選択だけでテストでき、GitHubへのアップロードは不要です。
プレイ中は一時停止してから読み込んでください。新しい譜面は最初からのプレイになります。

## 公開する譜面を更新する場合

1. GitHubでこのフォルダーの `Rolling_Game.mid` を追加・上書きし、`main` に保存します。
2. GitHub Pagesの公開処理が完了したら、ゲームで「公開MIDIを再読み込み」を押します。
3. ページを開き直した場合も、同じ場所のMIDIを自動で読み込みます。

再読み込みではブラウザーのキャッシュを使いません。公開処理が完了する前は旧版が返ることがあります。
ファイル不在・読み込み失敗時は、その旨を表示し、現在の譜面を維持します。

## REAPERでの譜面ルール

| キー | MIDIノート番号 | 音名 |
| --- | --- | --- |
| Q | 75 | D♯ |
| W | 74 | D |
| E | 73 | C♯ |
| R | 72 | C（中央ドの1オクターブ上） |

- オクターブ表記はDAWの設定によって変わるため、ノート番号を基準にします。
- ノートの先頭が押すタイミング。同時押しは異なるレーンに同時刻で配置します。
- 4分音符より短い音符はタップ（16分音符の長さを推奨）。4分音符以上は長押しです。
- 長押しは、その音符の長さの **80％** を押し続けると成功します。
  例：2秒の長押しなら1.6秒で成功。成功後はいつ離しても、押し続けても減点しません。
  開始時のタイミング判定はあります。成功前に離すと長押し部分がMISSになります。
- 音源の0秒とMIDIの0秒を揃え、冒頭の休符を残します。ファイル全体の長さは音源と一致しなくても構いません。
- Rollingは162 BPM。譜面トラックとテンポ情報を含めてStandard MIDI（Type 0または1）で書き出します。
- 現在は音源の冒頭60秒が対象です。60秒以降の音符は省略し、境界をまたぐ長押しは短縮します。
- 同じレーンで重なる音符は作らないでください。別レーンの同時押しは対応しています。
